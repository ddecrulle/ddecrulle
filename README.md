## 🧠 My approach

- Advocating for **contract-first development** with OpenAPI, OIDC and typed APIs.
- Applying **hexagonal architecture** and clean layering in service design.
- Prioritizing **developer experience (DX)** and long-term maintainability.
- Building **reproducible environments** (infrastructure & data) through containerization and GitOps workflows.
- Embracing **type safety** across the stack (Go, TypeScript, schema validation).
